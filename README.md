# Zomato Restaurant Exploratory Data Analysis (EDA)

## Overview
An Exploratory Data Analysis (EDA) of Zomato restaurant ratings, costs, and customer preferences using Python. This project aims to uncover actionable insights into the dining landscape, pricing strategies, and factors that influence restaurant success.

## Key Insights Discovered
*   **Online Order Availability:** Visualized the "Distribution of Online Orders or Not" using a bar chart to compare the volume of restaurants offering digital delivery versus offline-only establishments.
*   **Table Booking Trends:** Analyzed the prevalence of advance reservations via a pie chart, showing that **28.57%** of restaurants provide a "book table" option.
*   **Premium Dining Costs:** Grouped the dataset to identify the Top 10 most expensive restaurants, led by **Django** for the highest average cost for two people.
*   **Highest Rated Chains:** Ranked the Top 10 restaurants by their average rating, revealing **Onesta** as the most consistently highly-rated dining option.

## Technologies Used
*   **Language:** Python
*   **Environment:** Jupyter Notebook
*   **Libraries:** Pandas, NumPy, Matplotlib, Seaborn

## Setup and Installation
To run this notebook locally, follow these steps:

1. Clone the repository:
   `git clone https://github.com/YashGhodke-source/Project-Zomato.git`
2. Activate your virtual environment:
   `source .venv/bin/activate` *(Linux/macOS)* or `.venv\Scripts\activate` *(Windows)*
3. Install the required dependencies:
   `pip install pandas numpy matplotlib seaborn jupyter`
4. Launch the notebook:
   `jupyter notebook`
